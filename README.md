# Groupie Tracker

Groupie Tracker is a web application for tracking artists/bands based on various criteria such as creation date, first album date, number of members, and locations of concerts.

## Features

- Filter artists/bands by creation date.
- Filter artists/bands by first album date.
- Filter artists/bands by number of members.
- Filter artists/bands by locations of concerts.

## Technologies Used

- Backend: Go
- Frontend: HTML, CSS, JavaScript


## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/malcoulibaly/groupie-tracker-filters.git

cd groupie-tracker

go run .
```
